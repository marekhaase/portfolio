# Marek Haase – Portfolio

My personal portfolio website. It's written by hand in plain HTML and CSS, with no frameworks and no build step.

## Pages

- `index.html` – home
- `about.html` – about me
- `services.html` – skills
- `projects.html` – projects
- `contact.html` – contact (the only page with a bit of JavaScript, for the copy buttons)

All styling is in `style.css`. It follows the system's light or dark mode.

## Run it locally

Just open `index.html` in a browser. Fonts (Newsreader, Public Sans, JetBrains Mono) load from Google Fonts, so you need to be online to see them.
